# 🛒 Seoudi-Market Dashboard

This Power BI dashboard was developed to provide a comprehensive overview of sales performance, customer behavior, and product insights for the Seoudi Market retail environment.

## 📊 Project Overview

The dashboard visualizes real-time data to support data-driven decision-making in areas such as sales strategy, product stocking, and customer targeting.

## ✅ Key Features

- **Revenue and Sales KPIs**  
  Displayed total revenue and quantity sold using clear numeric indicators.

- **Top Customers Panel**  
  Identified the top 7 customers by purchase volume to support targeted loyalty campaigns.

- **Product Performance Analysis**  
  - Quantity sold by product type (Fruit vs. Vegetable)  
  - Top 3 and least 3 sold products visualized with donut charts.

- **Sales by Demographics**  
  Sales trends by customer age groups to identify generational buying patterns.

- **Branch-Level Filtering**  
  Slicer options for branches such as Dokki, Nasr City, and New Cairo to allow localized performance analysis.

## 🛠 Tools & Technologies

- **Power BI** – For data visualization and dashboard design  
- **Microsoft Excel / CSV** – As the data source (sample/mock data)  
- **Data Modeling** – Applied basic transformations and measures for clean visuals
